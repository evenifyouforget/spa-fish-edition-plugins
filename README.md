# spa-fish-edition-plugins

Plugins for Stronghold Protocol: Alliance (Fish edition, beta).

They bring [Fish Edition](https://github.com/evenifyouforget/Stronghold-Protocol-EN)'s Custom Lobby Modifications to
any server running the game's plugin system (0.3.x,
[docs/PLUGINS.md](https://github.com/sganggs/Stronghold-Protocol/blob/master/docs/PLUGINS.md)). Only the parts that fit
the plugin system are here. SPA-CC, Fish Edition's Contingency-Contract-style Risk tags, stays in Fish Edition itself:
some of its tags need engine support plugins don't have
([#52](https://github.com/evenifyouforget/Stronghold-Protocol-EN/issues/52)).

## The plugins

Built and tested against the game version in [GAME_VERSION](GAME_VERSION) (v0.3.3); each one declares
`"app": ">=0.3.3 <0.4.0"`. None runs code, so they work on any server: `SP_PLUGIN_SCRIPTS` is not needed.

| Plugin | What it does |
|---|---|
| `fish-extra-funds` | Cheat: every Doctor gains 2 extra Funds at the start of every round. |
| `fish-extra-deploy` | Cheat: every Doctor's Deployment Limit +2. |
| `fish-double-lp` | Cheat: every Doctor's starting LP is doubled (each Strategy's starting LP × 2). |
| `fish-untimed` | Cheat: the Rest Phase has no countdown; the battle starts once every Doctor is ready. Battles keep their time limit. Solo is untimed already. |

Each plugin is one switch: the room's host turns it on in the room's 插件 panel. As with every gameplay plugin, the
game marks those matches unofficial (非官方).

Compared with Fish Edition's own rules: there, "untimed" also takes the countdown off the Strategy draft and Improv,
and the result screen says "WITH CHEATS". Plugins can do neither.

## Installing (server owners)

Each [release](https://github.com/evenifyouforget/spa-fish-edition-plugins/releases) has every plugin's zip and its
SHA-256 (`SHA256SUMS`). On the server, from the game's folder:

```sh
node tools/plugin.mjs install https://github.com/evenifyouforget/spa-fish-edition-plugins/releases/download/<tag>/<plugin>-<version>.zip --sha256 <its sha256>
```

or unzip a plugin into `plugins/<plugin id>/`. `node tools/plugin.mjs list` shows what the server found.

## Development

```sh
node tools/ci.mjs                # clone the game at GAME_VERSION into .game/, then check, test and pack every plugin
node tools/ci.mjs fish-untimed   # only the plugins named
node tools/test.mjs <id>         # only the tests of one plugin (after a ci.mjs run copied it into the game)
node tools/gen.mjs               # rewrite the data files computed from the game's data (after GAME_VERSION moves)
```

`SP_GAME_DIR=<path>` uses an existing game checkout instead of `.game/`.

- `plugins/<id>/` is exactly what ships: `plugin.json` and the files it names. A data-only plugin may not carry `.js`,
  so its tests live in `tests/<id>/` and run with the plugin's content set installed (`tools/test.mjs`), against the
  game's own match harness.
- `fish-double-lp` and `fish-untimed` are generated by `tools/gen.mjs` from the game's data (a data patch can only set
  values, not compute them). CI fails when they are out of date for `GAME_VERSION`.
- Pushing a tag `v*` runs the same checks and publishes the zips as a release.
